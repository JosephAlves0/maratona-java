# ☕ Maratona Java - DevDojo

Repositório contendo os códigos, exercícios e exemplos desenvolvidos durante o curso **Maratona Java** do canal **DevDojo**.

## 📚 Sobre o curso

A **Maratona Java** é um dos cursos mais completos de Java disponíveis gratuitamente, abordando desde os fundamentos da linguagem até conceitos avançados de Programação Orientada a Objetos, Collections, Threads, Streams e muito mais.

## 🎯 Objetivo

Este repositório tem como objetivo:

* Praticar os conceitos ensinados no curso;
* Registrar minha evolução na linguagem Java;
* Manter um histórico das aulas utilizando Git e GitHub;
* Servir como material de consulta para estudos futuros.

## 🛠️ Tecnologias

* ☕ Java
* 💻 IntelliJ IDEA
* 🐧 Ubuntu Linux
* 🌱 Git
* 🐙 GitHub
